1. Introduction to AI مقدمة

AI vs Machine Learning vs Deep Learning

AI: The big umbrella. Any machine acting smart.

Machine Learning (ML): Manual feature extraction. Good for simple data.

Deep Learning (DL): Automatic feature extraction using Neural Networks. Essential for images/video.

Crucial Concept: Inference vs. Training الاستنتاج مقابل التدريب

Training (Learning)

Teaching the model new information (e.g., your face).

  • Requires heavy GPU (VRAM).
  • Takes hours/days.

Inference (Using)

Using a ready model to generate images.

  • 99% of what you do in ComfyUI.
  • Fast and lighter.

Training (التدريب)

تعليم الموديل معلومات جديدة (مثل وجهك).

  • يحتاج كارت شاشة قوي (VRAM).
  • يستغرق ساعات أو أيام.

Inference (الاستنتاج)

استخدام موديل جاهز لتوليد الصور.

  • 99% من عملك داخل ComfyUI.
  • سريع وخفيف على الجهاز.
