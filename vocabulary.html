Vocabulary List قائمة المصطلحات

The essential dictionary for your AI journey.

Term المعنى العربي Definition
Core Concepts
Artificial Intelligence (AI) الذكاء الاصطناعي Machines mimicking human intelligence.
Machine Learning (ML) تعلم الآلة Computers learning from data without explicit programming.
Inference الاستدلال Using a trained model to generate/predict (Fast).
Quantization التكميم Compressing weights (FP32 -> INT8) for speed/size.
GGUF صيغة GGUF File format for quantized models, optimized for CPU/Mac.
Transformer المحول Architecture using Self-Attention to understand context.
OpenAI (Closed Source) أوبن إيه آي (مغلق المصدر) The company behind ChatGPT & DALL-E. You can't see or change their code/models.
Flux (Open Weights) موديل فلكس (أوزان مفتوحة) State-of-the-art Model (2024) by Black Forest Labs. Excellent at spelling text within images.
Diffusion Model نموذج الانتشار The AI system used to generate images. To work, it MUST have 3 parts: CLIP (to read), U-Net (to draw), and VAE (to see).
CivitAI موقع CivitAI The #1 website to download Models, LoRAs, and find the "Golden Settings" (CFG/Steps).
Sampler خوارزمية الرسم (العينات) The algorithm / tool that calculates the math to remove noise (e.g. Euler, DPM++).
Scheduler الجدولة (المخطط الزمني) The timetable / plan. It decides how much noise to remove at each step (Fast start? Slow end?).
Training
Epoch حقبة / دورة One complete pass through the entire training dataset.
Weights الأوزان The parameters (numbers) the model adjusts to learn.
Overfitting فرط التخصيص Memorizing exact data instead of learning general rules.
Data Types
Integer (int) عدد صحيح Whole numbers without decimals (e.g., 1, 42, -5).
Float عدد عشري / فاصلة عائمة Numbers with decimal points (e.g., 3.14, -0.01).
String (str) سلسلة نصية Text data enclosed in quotes (e.g., "Hello").
Boolean (bool) منطقي / بولياني True or False values.
Operations Nodes عقد العمليات Nodes used to perform math or logic on data types to drive other properties.
Stable Diffusion Parts
CLIP / Text Encoder مشفر النصوص The eyes & ears of the model. It encodes your text prompt into vectors so the Diffusion Model can understand it.
U-Net الشبكة الرابطة The actual "Brain" that processes the noise.
VAE (Variational Autoencoder) المشفّر التلقائي (VAE) The "Final Translator". It takes the hidden mathematical image (Latent) and explains/decodes it into visible pixels.
Latent Space الفضاء الكامن Compressed mathematical representation of the image ("The Recipe").
ControlNet شبكة التحكم Controlling generation structure (Pose, Canny, Depth).
Checkpoints نقاط الحفظ / الموديل Saved model states (SafeTensors). Usually contains Model + CLIP + VAE (Baked).
Baked VAE VAE مدمج When the VAE is already inside the Checkpoint (No red wire needed). Diffusion Models (UNETs) often don't have this.
LoRA لورا Small "plug-in" files to add specific styles or characters to a Checkpoint.
CFG Scale مقياس الالتزام (التباين) How much the AI sticks to the prompt. Higher = More Contrast & Details. Lower = More Creative / Soft.
ComfyUI Basics
ComfyUI واجهة كومفي Node-based interface for building complex AI generation pipelines.
Seed البذرة The random number starting point. Same Seed = Same Image.
Sampler خوارزمية العينات The math strategy used to remove noise (e.g., Euler a, Karras).
Steps الخطوات Number of cleaning cycles. More steps = Slower but more detailed. usually 20-30.
CFG Scale مقياس التوجيه "Classifier Free Guidance". Controls how much the AI listens to your prompt. (7 is Balanced).
Denoise تقليل الضوضاء (لمسة التغيير) Controls how much creativity the AI adds. Used in Image-to-Image. 1.0 = Max Change.
KSampler (Advanced) العينات المتقدم A version of KSampler that lets you specify "Start Step" and "End Step". Used for Refiners.
Refiner المصقل A specialized model (like SDXL Refiner) used only for the last few steps to clean up details.
Workflow سير العمل The visual arrangement of connected nodes, savable as JSON.
Custom Tools
Copilot المساعد الآلي AI assistant helping to build workflows or answer questions.
rgthree أدوات rgthree Essential toolkit for power users (Mute, Bypass, Fast Groups).
Crystools أدوات Crystools System monitor (VRAM, RAM, GPU usage).
LogicUtils أدوات المنطق Nodes for boolean logic, comparisons, and data flow control.
Controls
Bypass (Bridge) تجاوز (جسر) Skips the node but passes the signal to the next one (Ctrl+B).
Disable (Wall) تعطيل (جدار) Stops the node completely. Flow ends here (Ctrl+M).
Group Node مجموعة عقد A container box to move and organize multiple nodes together.
Subgraph (Convert to Node) سير عمل فرعي (عقدة مجمعة) Compressing many nodes into ONE single node (Workflow inside a Workflow).
Concatenate دمج النصوص Joining two or more text strings together (e.g. "Cyber" + "punk" = "Cyberpunk").
Primitive Node عقدة بدائية A generic node that acts as a raw data source (can be converted to Int, Float, String).
Widget أداة إدخال (مربع) The value box inside the node itself (Standard input).
Input Slot (Convert to Input) منفذ الدخل (نقطة التوصيل) When you right-click a widget to turn it into a connectable "dot" for wires.
Type Casting تحويل النوع Converting one data type to another (e.g. turning the Number 5 into the Text "5").
Metadata البيانات الوصفية Hidden information within the image file. In ComfyUI, it saves the Entire Workflow (Nodes & Settings).
