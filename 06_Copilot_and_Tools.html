6. Copilot & Essential Tools أدوات المساعد والأساسيات

Supercharging ComfyUI 🚀 تعزيز قدرات ComfyUI

ComfyUI is powerful, but "Vanilla" (default) ComfyUI can be hard to manage. Custom Tools make your life easier by adding features like Logic, System Monitoring, and Workflow Assistance.

برنامج ComfyUI قوي، ولكن النسخة "الخام" (الافتراضية) قد تكون صعبة الإدارة. الأدوات المخصصة تجعل حياتك أسهل عبر إضافة ميزات مثل المنطق، مراقبة النظام، و مساعد سير العمل.

The "Must-Have" List 🛠️ قائمة الأدوات الضرورية
1. rgthree-comfy أدوات rgthree

The "Power User" suite. It adds:

  • Mute / Bypass: Quickly turn off parts of your workflow without deleting them.
  • Fast Groups: Organize nodes into clean, labeled boxes.
  • Context: Pass data between nodes without messy wires.

مجموعة "المستخدم المحترف". تضيف:

  • كتم / تجاوز (Mute/Bypass): إيقاف أجزاء من العمل بسرعة دون حذفها.
  • مجموعات سريعة: تنظيم العقد داخل صناديق نظيفة ومعنونة.
  • السياق (Context): تمرير البيانات بين العقد بدون أسلاك فوضوية.
2. ComfyUI-Crystools أدوات Crystools

Your Dashboard. It shows a small bar inside ComfyUI displaying:

  • VRAM / RAM Usage: See if your model is too big for your GPU.
  • GPU Load: Watch your graphics card work in real-time.

لوحة القيادة الخاصة بك. تظهر شريطاً صغيراً داخل ComfyUI يعرض:

  • استهلاك الذاكرة (VRAM/RAM): لتعرف إذا كان الموديل أكبر من قدرة كارت الشاشة.
  • ضغط المعالج الرسومي: شاهد كارت الشاشة وهو يعمل في الوقت الفعلي.

⚠️ Hardware Safety Warning 🌡️

تحذير سلامة الأجهزة

WATCH YOUR TEMPS! AI generation is very heavy. Use Crystools to monitor your GPU temperature.

  • ✅ Below 70°C: Safe for long runs.
  • ⚠️ 70°C - 80°C: High. Okay for a quick task, but not for hours.
  • 🛑 Above 80°C: DANGEROUS. Stop immediately. Bad for hardware lifespan.

Cooling Tips: Turn on AC, put a fan in front of the PC, and run only one task at a time.

راقب الحرارة! توليد الذكاء الاصطناعي عملية ثقيلة جداً. استخدم Crystools لمراقبة حرارة كارت الشاشة.

  • ✅ أقل من 70°C: آمن للعمل الطويل.
  • ⚠️ 70°C - 80°C: مرتفع. مقبول لمهمة سريعة، لكن ليس لساعات.
  • 🛑 فوق 80°C: خطر جداً. توقف فوراً. هذا يؤذي جهازك.

نصائح التبريد: شغل التكييف، ضع مروحة أمام الكيسة، وشغل مهمة واحدة فقط في المرة.

3. ComfyUI-LogicUtils أدوات المنطق

The Brain. Allows you to use "Programmer Logic" in your images.

  • If / Else: "If image is dark, brighten it. Else, leave it."
  • Comparisons: Check if Number A > Number B.
  • Data Types: Convert Integer to Float, String to Bool, etc.

العقل المدبر. يسمح لك باستخدام "منطق المبرمجين" في صورك.

  • إذ / وإلا (If/Else): "إذا كانت الصورة مظلمة، فتحها. وإلا، اتركها."
  • المقارنات: تحقق مما إذا كان الرقم A > الرقم B.
  • أنواع البيانات: تحويل الأرقام الصحيحة لعشرية، والنصوص لمنطقية، إلخ.
Basic Controls & Settings 🎛️ عناصر التحكم الأساسية
Bypass vs Disable التجاوز مقابل التعطيل

🚫 Disable (Ctrl + M): Acts like a Wall. The node stops working, and anything after it also stops.

🌉 Bypass (Ctrl + B): Acts like a Bridge. The node is skipped, but the wire continues to the next node as if this one wasn't there.

🚫 التعطيل (Disable): يعمل مثل الجدار. تتوقف العقدة عن العمل، وكل ما بعدها يتوقف أيضاً.

🌉 التجاوز (Bypass): يعمل مثل الجسر. يتم تخطي العقدة الحالية، ولكن السلك يمر للعقدة التالية وكأن هذه العقدة غير موجودة.

Group Nodes تجميع العقد (المجموعات)

Right-click -> Add Group. Creates a movable box. Put nodes inside it to move them all together. Essential for keeping big workflows clean.

زر أيمن -> Add Group. ينشئ صندوقاً متحركاً. ضع العقد داخله لتحريكها معاً. ضروري للحفاظ على نظافة المشاريع الكبيرة.

Custom Settings الإعدادات المخصصة

Some nodes (like LogicUtils or Custom Connectors) have hidden settings. Right-click the node to see options like "Convert Widget to Input" or access specific tool settings.

بعض العقد (مثل LogicUtils) لها إعدادات مخفية. اضغط بالزر الأيمن على العقدة لرؤية خيارات مثل "تحويل الأداة إلى مدخل" (Convert Widget) أو إعدادات الأداة الخاصة.

ComfyUI-Copilot 🤖 مساعد ComfyUI

Just like we are talking now, Copilot nodes allow you to chat with an AI inside ComfyUI to build workflows for you.

It can suggest nodes, fix connections, or even explain what a specific node does.

تماماً كما نتحدث الآن، عقد Copilot تسمح لك بالدردشة مع ذكاء اصطناعي داخل ComfyUI ليقوم ببناء سير العمل نيابة عنك.

يمكنه اقتراح عقد، إصلاح التوصيلات، أو حتى شرح وظيفة عقدة معينة.
