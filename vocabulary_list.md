# Vocabulary List | قائمة المصطلحات

| English Word | Arabic Meaning | Simple Definition (English) |
| :--- | :--- | :--- |
| **Artificial Intelligence (AI)** | الذكاء الاصطناعي | machines thinking like humans |
| **Machine Learning (ML)** | تعلم الآلة | computers learning from data |
| **Deep Learning (DL)** | التعلم العميق | learning using neural networks |
| **Epoch** | حقبة / دورة تدريب كاملة | one full pass of the training data |
| **Batch Size** | حجم الدفعة | number of samples treated at once |
| **Weights** | الأوزان | importance of a specific feature |
| **Overfitting** | فرط التخصيص / حفظ البيانات | learning too much detail (memorizing) |
| **Underfitting** | قصور التدريب | failing to learn the pattern |
| **Diffusion** | الانتشار | creating data (images) from noise |
| **Inference** | استدلال | when the model makes a prediction after learning |
| **Contamination** | تلوث البيانات | when test data leaks into training data |
| **Transformers** | المحولات | modern architecture for language understanding |
