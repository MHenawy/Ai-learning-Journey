5. The ComfyUI Manager مدير ComfyUI

Why do you need this? 🧠 لماذا تحتاج هذا؟

Imagine buying a smartphone without an App Store. That is ComfyUI without the Manager.

The Manager connects your local ComfyUI to thousands of developers around the world. It assumes the role of a "System Administrator" for you, handling updates, installations, and missing files automatically.

تخيل أنك تشتري هاتفاً ذكياً بدون متجر تطبيقات (App Store). هذا هو ComfyUI بدون الـ Manager.

المدير (Manager) يربط نسختك بآلاف المطورين حول العالم. هو يقوم بدور "مدير النظام" نيابة عنك، فيتولى التحديثات، والتثبيت، وتوفير الملفات الناقصة تلقائياً.

Key Features Explained 🛠️ شرح المميزات الأساسية
1. Install Missing Custom Nodes تثبيت العقد الناقصة
The "Magic Fixer". When you download a workflow from the internet and see RED NODES, it means you don't have the tools installed. Click this button, and it finds them for you.
"المصلح السحري". عندما تحمل ملف عمل (Workflow) من الإنترنت وترى عقداً حمراء، فهذا يعني أنك تفتقد الأدوات اللازمة. اضغط هذا الزر، وسيقوم هو بإيجادها وتثبيتها لك.
2. Update All تحديث الكل
AI moves fast. Code changes daily. This button updates ComfyUI itself AND all your installed extensions. Use it once a week.
الذكاء الاصطناعي يتطور بسرعة. الكود يتغير يومياً. هذا الزر يحدث ComfyUI نفسه وجميع الإضافات المثبتة لديك دفعة واحدة. استخدمه مرة أسبوعياً.
3. Model Manager مدير الموديلات
Instead of hunting for files on websites like CivitAI, search for "Juggernaut" or "Realistic Vision" here and click Install. It puts the file in the correct folder automatically.
بدلاً من البحث عن الملفات في مواقع مثل CivitAI، ابحث عن اسم الموديل هنا (مثل Juggernaut) واضغط Install. سيضع الملف في المجلد الصحيح تلقائياً.
Dr. Note 👨‍🏫 ملاحظة الخبير

Restarting is Mandatory: Unlike normal apps, ComfyUI creates a loaded environment in memory.

Whenever you Install or Update anything via the Manager, you MUST click the RESTART button (or close the black window and open it again) for changes to work.

إعادة التشغيل إجبارية: بعكس البرامج العادية، ComfyUI يبني بيئة عمل كاملة في الذاكرة.

كلما قمت بتثبيت أو تحديث أي شيء، يجب عليك ضغط زر RESTART (أو إغلاق الشاشة السوداء وفتحها) لكي تعمل التغييرات.
